# E017: E013 + 最近傍の制限を外す

状態: submitted（version 1 を 2026-09-27 12:01 JST に提出した。提出 ID 56596041。採点中）

- 目的: 名前は mutual-NN だが、実際は一方向の制限（既存の娘 c1 に最も近い候補だけを許す）。これを外すと候補が増え、娘の選び方も変わる（`score = parent_dist + 0.15 * sister_dist` が小さい候補が優先される）。低リスクな改良ではなく、比較のための実験。
- 生成: `python3 server/make_e016_e019.py`。E006 の Notebook に、E013 の設定（rescue 0.5）と診断ログを足し、そのうえで次の変更を入れる。
- Kernel: `versavice/biohub-e017-x138-r05-nomutualnn`

## 事前に決めた判断の基準（2026-09-27、結果を見る前に決めた）

- 比べる相手は E013（0.959）。分裂の数が増えただけでは成功としない。既存の親で娘が入れ替わった件数も `server/diff_outputs.py` で確かめる。
- 0.960 以上: 新しい候補の中で最高なら、最終提出は「この版 + E013」にする。複数ある場合や同点の場合は、`docs/session_handoff.md` の統一ルールに従う。
- 0.959 以下: 最終提出は E013 + E010 のまま。
- 実行時のエラー、`REPAIR FAILED`、実行時間の大きな増加は、スコアとは分けて扱う。
- 診断ログ `SAFEDIV_DIAG`（divergence で落ちた組を、後続がないものと距離が足りないものに分けて数える。距離が 1.25〜2.25 µm のものの数と、フレームの上限で使われなかった候補の数も数える）を読む。判断は変えず、ログを出すだけ。

# A001: 公開 DivNet の重みを学習データの正解ラベルで検証

状態: complete（サーバーの GPU 0、2026-09-24）

- 目的: `giorgosi/biohub-divnet-v2` の `best_overall.pt` を、前処理を正しく再現したうえで動かせるか確かめる。
- スクリプト: `server/divnet_check.py`
  - モデル: DeepCenterUNet3D(5, 16) の本体に、dec1 の global average pool と Linear(16, 1) を付けたもの。`strict=True` で読み込めた。
  - 入力: フレーム t-1, t, t+1, t+2 を xy 方向に 4 倍 pooling し、フレームごとに p50/p99.5 で正規化して `clip(-0.5, 6)`。親の位置で 16×32×32 に crop し、最後のチャンネルに親中心のガウシアン marker（sigma 1.5, 2, 2）を置く。
  - 正例: 正解ラベルで出次数 2 のノード（151 件）。負例: 出次数 1 のノードを、分裂のあるフレームとランダムな 3 フレームから、動画ごとに最大 40 件。
- 結果:
  - AUC 0.832（n=4,574）。marker を先頭にすると AUC 0.611 なので、今のチャンネルの順番が正しい。
  - 同じフレームの細胞の中で、分裂する親が 1 位になるのは 67%、3 位以内が 85%。
  - スコアは約 0.26 と約 0.76 の 2 つの山に分かれる。
- 注意: `best_overall.pt` は 1 fold 分の重み（その fold の AUC 0.893）で、学習データの約 3/4 を学習に使っている。今回の値の大半は in-sample。作者の値（OOF で 0.845）より低いので、前処理に細かいずれが残っている可能性がある。
- 出力: サーバーの `runs/divnet_check/`（`scores_base.npz`、`summary_*.json`）
